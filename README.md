# DermaMNIST skin-lesion classification challenge

Deep Learning exam project: classify 28×28 dermatoscopy images into 7 lesion
types, maximise **balanced accuracy** on the official test split, and compare
every improvement fairly against the starter baseline (≥3 seeds, mean ± std,
95 % bootstrap interval of the difference).

Team: **Am besten** — Ossai Ron, Ifroon Griffin, Faraz Saedi

## Results

### Final model (frozen at commit `863f3ce`, tag `v1.0-final`)

Logit-adjusted loss + ImageNet-pretrained ResNet-18 (28×28 upsampled to 112×112
inside the model) + random flips and 90° rotations, 10 epochs; the three seed
models (0, 1, 2) are averaged into one TorchScript module, `model.pt`
(input: normalised `(N, 3, 28, 28)`, output: `(N, 7)` logits).

Test split, evaluated **once**, after the model was frozen. Both rows are
3-seed ensembles; Δ is the paired bootstrap interval on the 2 005 test images.

| Model | Test BalAcc | Δ vs baseline [95 % CI] | Test macro-F1 | akiec | bcc | bkl | df | mel | nv | vasc |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Baseline (starter CNN) | 0.448 | — | 0.479 | 0.33 | 0.55 | 0.46 | 0.09 | 0.34 | 0.91 | 0.45 |
| **Final** | **0.632** | **+0.184 [+0.136, +0.232]** | 0.500 | 0.52 | 0.50 | 0.55 | 0.57 | 0.64 | 0.73 | 0.93 |

Per-class columns are test sensitivities. Test class sizes: 66, 103, 220, 23,
223, 1 341, 29 — df and vasc sensitivities move 3–4 points per image.

### Every variant on the validation split

Mean ± std over seeds 0, 1, 2. Δ: paired bootstrap (2 000 resamples of the
1 003 val images, all seeds of both models scored on the same resample).
Variants built on another variant are also compared with that parent.
Generated by `scripts/summarize.py` (`results/summary.md`); per-seed intervals
from the starter's own `bootstrap_difference` are in `results/starter_bootstrap.md`.

| Variant | One change | Val BalAcc | Δ vs baseline [95 % CI] | Δ vs parent [95 % CI] | Val macro-F1 |
| --- | --- | --- | --- | --- | --- |
| B0 `baseline` | starter CNN, Adam 1e-3, batch 64, 10 epochs | 0.461 ± 0.011 | — | — | 0.470 ± 0.007 |
| E1 `e1_class_weights` | class-weighted cross-entropy | 0.515 ± 0.016 | +0.054 [+0.023, +0.092] | — | 0.400 ± 0.022 |
| E2 `e2_logit_adjusted` | logit-adjusted loss, τ = 1 | 0.532 ± 0.031 | +0.071 [+0.029, +0.118] | — | 0.400 ± 0.028 |
| E3 `e3_flip_rot` | flips + 90° rotations | 0.462 ± 0.016 | +0.001 [−0.025, +0.026] | — | 0.480 ± 0.015 |
| E4 `e4_trivialaugment` | TrivialAugment | 0.329 ± 0.024 | −0.133 [−0.169, −0.098] | — | 0.367 ± 0.023 |
| E5 `e5_improved_cnn` | BatchNorm, dropout, 4 wider blocks | 0.458 ± 0.047 | −0.003 [−0.035, +0.027] | — | 0.466 ± 0.050 |
| E6 `e6_cosine` | cosine LR schedule, 2 warm-up epochs | 0.417 ± 0.016 | −0.044 [−0.068, −0.019] | — | 0.445 ± 0.018 |
| E7 `e7_resnet18` | pretrained ResNet-18 at 112 px | 0.493 ± 0.051 | +0.032 [−0.011, +0.075] | — | 0.494 ± 0.052 |
| E8 `e8_sam` | SAM (ρ = 0.1) on top of E2 | 0.517 ± 0.028 | +0.056 [+0.009, +0.108] | −0.015 [−0.044, +0.014] vs E2 | 0.375 ± 0.028 |
| E9 `e9_posthoc_la` | post-hoc logit adjustment of B0, τ = 1.25 chosen on val¹ | 0.545 ± 0.023 | +0.083 [+0.041, +0.131] | — | 0.364 ± 0.023 |
| E10 `e10_epochs30` | 30 instead of 10 epochs | 0.466 ± 0.002 | +0.005 [−0.025, +0.037] | — | 0.490 ± 0.008 |
| S1 `s1_la_resnet18` | stack: E2 + E7 | 0.575 ± 0.035 | +0.114 [+0.061, +0.170] | +0.043 [−0.018, +0.100] vs E2 | 0.509 ± 0.044 |
| S2 `s2_la_resnet18_fliprot` | stack: S1 + E3 | 0.590 ± 0.017 | +0.129 [+0.078, +0.181] | +0.016 [−0.028, +0.054] vs S1 | 0.478 ± 0.022 |
| **Final** | S2, 3 seeds averaged | **0.609** (one ensemble) | | | 0.505 |

¹ τ is selected on the same val images it is scored on, so this row is slightly optimistic.

Stacking rule (roadmap, stage 2): start from the best single change (E2), add
the next change, keep it only if the val mean improves. E1 was not stacked with
E2 because both correct the same imbalance. The final choice — S2 and the seed
ensemble — was made on val only.

What the table says, in short:
- Both imbalance corrections (E1, E2, E9) clearly help balanced accuracy, mainly
  by finding dermatofibroma (val sensitivity 0.03 → 0.22–0.58), at the cost of
  nevus sensitivity (0.89 → about 0.5–0.6) and macro-F1.
- The pretrained ResNet alone is not a clear gain, but together with the
  logit-adjusted loss it gives the largest step; it also keeps nevus
  sensitivity higher (0.76), so macro-F1 recovers.
- Training longer (E10), a bigger plain CNN (E5) and flips on the small CNN
  (E3) show no clear effect; TrivialAugment (E4) and the cosine schedule (E6)
  are clearly worse with the fixed 10-epoch budget.

Figures (in `results/figures/`, made by `scripts/make_figures.py`):
`class_counts.png`, `examples.png`, `forest_delta.png` (every Δ with its CI),
`sensitivity.png` (per class, baseline vs final), `confusion_*.png`, `curves.png`.

## Repository layout

```
configs/            one YAML per variant; each inherits its parent and changes one thing
src/
  data.py           DermaMNIST loading, MEAN/STD normalisation, augmentation
  models.py         baseline CNN, improved CNN, ResNet with upsampling inside the model
  losses.py         cross-entropy, class-weighted CE, logit-adjusted loss, focal loss
  sam.py            Sharpness-Aware Minimisation optimiser
  train.py          train(config, seed) -> results/<variant>/seed<k>/
  evaluate.py       balanced accuracy, macro-F1, per-class sensitivity, bootstrap CI
  export.py         TorchScript export of the final model + load-and-compare check
  utils.py          seeding, config inheritance, device, git hash
scripts/
  run_seeds.py      train one config with seeds 0, 1, 2
  posthoc_la.py     E9: post-hoc logit adjustment of saved logits, τ chosen on val
  summarize.py      results table (mean ± std, Δ vs baseline / parent with 95 % CI) from saved logits
  starter_bootstrap.py  the starter's per-seed bootstrap_difference, for comparison
  make_figures.py   forest plot, per-class sensitivity, confusion matrices, val curves
  to_tensorboard.py writes the saved per-epoch histories to runs/ for TensorBoard
  describe_data.py  class counts and example-image grid (Phase A)
  check_model.py    loads an exported model.pt on CPU and scores it on val
  app_assets.py     malignancy threshold, gallery images and model card for the app (val only)
  final_test.py     test-split evaluation, run once at the very end
tests/              fast checks on random images (no download needed)
notebooks/          the starter notebook, unchanged
app/                Gradio app: app.py (from app_template.py), app_config.json, examples/
report/             IEEE LaTeX report
results/            saved val logits and metrics per run, summary tables, figures, test results
```

## Setup

```bash
git clone https://github.com/<user>/dermamnist-challenge.git
cd dermamnist-challenge
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
pytest -q                                   # should pass in under a minute
```

**The committed results were produced on an Intel Mac** (Python 3.11,
torch 2.2.2, training on the AMD GPU via MPS). PyTorch publishes no Intel-Mac
wheels after 2.2.2, so on such a machine use Python 3.11 and
`pip install -r requirements-intel-mac.txt` instead; that file pins exactly the
versions behind `results/`.

GPU: `pip install torch` gives a CPU build on Windows/macOS. For an NVIDIA GPU,
install torch first with the command from https://pytorch.org/get-started/locally/,
then `pip install -r requirements.txt`. On Colab, torch is preinstalled.
DermaMNIST is downloaded to `data/` automatically on first use.

## Reproduce

Run time on the Intel Mac above: about 1 min per small-CNN run, about 17 min per
ResNet-18 run (10 epochs).

```bash
python scripts/describe_data.py                        # class counts + example grid
python scripts/run_seeds.py configs/baseline.yaml      # B0, seeds 0 1 2
python scripts/run_seeds.py configs/e1_class_weights.yaml
# ... one line per config in configs/ (e1 ... e10, s1, s2)
python scripts/posthoc_la.py                           # E9 from the saved baseline logits
python scripts/summarize.py                            # results/summary.md and .csv
python scripts/starter_bootstrap.py                    # per-seed intervals, starter's function
python scripts/make_figures.py --compare s2_la_resnet18_fliprot
python scripts/to_tensorboard.py && tensorboard --logdir runs

# final model and baseline, both as 3-seed ensembles
python -m src.export --config configs/s2_la_resnet18_fliprot.yaml --seeds 0 1 2 --out model.pt
python -m src.export --config configs/baseline.yaml --seeds 0 1 2 --out baseline.pt
python scripts/check_model.py model.pt                 # val bal_acc 0.6093
python scripts/final_test.py --models baseline.pt model.pt --i-have-frozen-the-model
```

`model.pt` (128 MB) is not in Git; it is rebuilt from the trained weights with
the export line above.

Single run: `python -m src.train --config configs/e3_flip_rot.yaml --seed 0`

## Rules this code follows

- Training uses the official **train** split only; models and settings are chosen on **val**.
- The **test** split is loaded only by `scripts/final_test.py`; it was run once, after the final model was frozen (commits `863f3ce` → `9ead38a`).
- Model input is (N, 3, 28, 28), normalised with the starter's MEAN/STD; output is (N, 7) logits.
- Every variant changes exactly one thing relative to its parent config and runs with 3 seeds.
